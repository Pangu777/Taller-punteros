## Descripción
Este repositorio contiene tres programas desarrollados en C++ enfocados en el uso de punteros, memoria dinámica y funciones aplicadas a estructuras de datos.

## Contenido

### Código 1
Programa que trabaja con **matrices dinámicas usando punteros**.  
Permite ingresar una matriz, calcular la suma de cada fila, encontrar el mayor elemento y generar su matriz transpuesta.

### Código 2
Programa que usa **punteros a funciones** para aplicar diferentes operaciones matemáticas a un arreglo dinámico (cuadrado, doble e inverso).

### Código 3
Programa que utiliza **lambdas y transformaciones encadenadas** para aplicar múltiples operaciones a los valores de un arreglo y luego combinarlos en un resultado final.

## Notas
Todos los programas se ejecutan en consola y utilizan memoria dinámica para manejar arreglos o matrices.
